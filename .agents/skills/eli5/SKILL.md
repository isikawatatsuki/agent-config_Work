# eli5

その話題をまったく知らない人にも理解できるように、大きな図と少ない言葉で構成したHTML成果物を使って説明する。

話題: $ARGUMENTS

## 保存先

保存先の明示指定がなければワークスペースルートの `.agents/artifacts/<topic>/<YYYY-MM-DD-slug>/index.html` に保存する。PDFと関連資産も同じ成果物フォルダーにまとめる。既存資料は自動移動しない。閲覧・検索は [成果物エクスプローラー](../../artifact-explorer/README.md) を参照する。
